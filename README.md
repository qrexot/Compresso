# Compresso

Программа для сжатия видео на Windows. Обрабатывает файлы локально с помощью FFmpeg.

## Возможности

- Сжатие MP4 и WebM, пакетная обработка и обрезка видео.
- Три уровня сжатия, оценка размера по коротким фрагментам.
- Кодирование на процессоре или NVIDIA NVENC для MP4 при поддержке драйвера.
- Русский и английский интерфейс.

## Скачать

[Последний выпуск](../../releases/latest) содержит один файл **Compresso.exe**. Требуются Windows 10/11 x64 и Microsoft Edge WebView2 Runtime. При запуске служебные компоненты временно извлекаются в системную папку.

## Сборка

На Windows установите Rust, Visual Studio Build Tools с компонентами C++ и WebView2. Затем запустите `build.bat`. Готовый файл появится в `release/Compresso.exe`. Скрипт загрузит FFmpeg, проверит контрольную сумму и соберёт приложение.

GitHub Actions выполняет сборку и публикует новый Release при изменении ветки `main` или ручном запуске workflow.

## Исходники

Rust-бэкенд, модуль запуска и дополнительные модули интерфейса находятся в репозитории. Основной интерфейс предоставлен как собранный JavaScript-бандл в `dist/`; исходные React-компоненты в исходном архиве отсутствовали.

FFmpeg распространяется на условиях своей лицензии: [FFmpeg-LICENSE.txt](FFmpeg-LICENSE.txt). Исходный код FFmpeg доступен на [ffmpeg.org](https://ffmpeg.org/download.html).
