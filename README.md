# Compresso

**Бесплатная программа для сжатия видео на Windows.** Уменьшайте размер файлов для отправки, публикации и хранения, выбирая удобный баланс между качеством и размером.

[Скачать Compresso.exe](https://github.com/qrexot/Compresso/releases/latest)

## Сжатие под вашу задачу

Выберите один из трёх уровней: **слабое**, **среднее** или **сильное** сжатие. Слабый режим бережнее относится к деталям, а сильный делает больший упор на уменьшение размера.

Результат зависит от исходного видео и выбранных настроек: сильное сжатие может заметно снизить качество. Перед запуском Compresso оценивает примерный размер готового файла по коротким фрагментам; фактический размер может отличаться.

## Возможности

- **MP4 и WebM** — выбирайте формат под свою задачу.
- **Пакетная обработка** — добавляйте несколько видео одновременно.
- **Обрезка видео** — сохраняйте нужный фрагмент.
- **NVIDIA NVENC** — используйте видеокарту для кодирования MP4 при поддержке оборудования и драйвера.
- **Русский и английский языки** — переключайте язык интерфейса в программе.

## Как это работает

Compresso обрабатывает видео на вашем компьютере с помощью **FFmpeg**. Приложение использует Tauri и Rust; интерфейс доработан на основе предоставленной версии Compresso.

Для Windows 10/11 x64 достаточно скачать один файл **Compresso.exe**. Приложению также нужен Microsoft Edge WebView2 Runtime.

Основной интерфейс находится в репозитории в виде собранного JavaScript-бандла; исходные компоненты интерфейса в предоставленном проекте отсутствовали. FFmpeg распространяется на условиях [своей лицензии](FFmpeg-LICENSE.txt).
